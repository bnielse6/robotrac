# Documentation index

The docs are grouped by what you want to do with them. Start with the folder that matches your question.

| Folder | Question it answers | Contents |
|---|---|---|
| `design/` | What is the robot, and why is it built this way? | Intended behavior, hardware choices, electrical plan, decision log |
| `software/` | How does the code work? | Message contract, Supervisor code, simulator, ESP32 firmware |
| `project/` | Where are we, and how do I run things? | Status, decisions, next steps, setup and troubleshooting |
| `planning/` | How was navigation and path planning worked out? | Findings for presenting, brainstorm records, navigation research, figures, sample schematics |
| `diagrams/` | (assets) Flowcharts and state charts | `.mmd` sources and `.png` renders, used by `design/complete_system_guide.md` |
| `original-flowcharts/` | (assets) The original hand-drawn flowcharts | Kept for reference |

## Where to put a new document

- Describes what the robot does or why a hardware choice was made: `design/`.
- Describes code, messages or the simulator: `software/`, and update the matching guide when behavior changes.
- Status, decisions to date, setup or how-to: `project/`.
- A dated session record, an analysis or research: `planning/`, with the date in the file name.
- Add a row to the table above and to the root `README.md` if it is a main document.
